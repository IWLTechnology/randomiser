# IWLTech Randomiser
A random picker for many different uses.

## Features:

 - Random colour picking (basic and advanced) 
 - Twister spinner mode.
 - Abiltiy to change the page background on colour change
 - Ability to set an automatic pick duration (e.g pick every 2s)
 - Saves settings to local storage
 - Ability to use basic speech synthesis
