# IWLTech Randomiser
A random picker with many different uses.

## Requirements
1. Any working browser. All features are local.

## Notes on testing

This project has not been tested very thoroughly on mobile devices or devices with small screens. Optimal performance may not be achievable on these devices.

Testing has mainly occurred on Firefox.

## How to use
Simply open the page, adjust all relevant settings, and click "Pick Random".

## Features:
 - Random colour picking (basic colours and all valid HTML colours) 
 - Twister spinner mode.
 - Abiltiy to change the page background on colour change
 - Ability to set an automatic pick duration (e.g pick every 2s)
 - Saves settings to local storage
 - Ability to use basic speech synthesis

## Live version
A hosted version of the project is available on the website (https://iwltechnology.github.io/randomiser).
